Google Maps API Key

到 Google Cloud Console 建立一個 API key，並在同一個專案啟用：
  1. Maps JavaScript API（地圖）
  2. Places API (New)（搜尋景點）
  3. Routes API（大眾運輸路線；舊版專案有開 Directions API 也可以）
直接用 file:// 打開時，key 不能設 HTTP referrer 限制。想加限制的話，在檔案所在資料夾跑 python3 -m http.server 8000，用 http://localhost:8000/ 打開，referrer 設成 http://localhost:8000/*。
Key 只會存在這個瀏覽器的 localStorage。
